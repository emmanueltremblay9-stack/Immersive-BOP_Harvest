# Immersive BOP Harvest 0.1.1

This stable candidate carries forward the qualified Biomes O' Plenty harvest
and sawmill compatibility for Minecraft 1.21.1 on NeoForge.

## Included

- Harvest behavior for the supported Biomes O' Plenty blocks remains covered
  by the source-derived GameTest and packaged-runtime evidence.
- Farmer's Delight, GlitchCore, TerraBlender, Biomes O' Plenty, and Immersive
  Engineering remain required runtime relations.
- The runtime artifact identity is `immersive_bop_harvest-0.1.1.jar`.
